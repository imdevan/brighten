# go-cli-template

Brighten (or darken) colors. Set the brightest color to white and scale remaining colors.

## Features

- Brighten colors to max brightness while maintaining color definition.
- Darken colors to max darkness while maintaining color definition.

## Author's Note

This project was created using [go-cli-template](https://devan.gg/go-cli-template/).

## Quick start

```bash
# install via homebrew tap
brew install imdevan/brighten/brighten

# brighten any color
brighten #f2ebe8
```
